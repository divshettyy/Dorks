# 🔎 Dorks

Curated **Google** and **Shodan** dork cheat-sheets for reconnaissance and OSINT — handy, copy-ready search queries for finding exposed files, panels, devices and misconfigurations. Served as simple web pages via GitHub Pages.

## 🌐 Open them

- **Google Dorking** → https://divshettyy.github.io/Dorks/Google.html
- **Shodan Dorking** → https://divshettyy.github.io/Dorks/Shodan.html

## 📋 What's inside

| Page | What it lists |
|------|---------------|
| `Google.html` | Google search operators and ready-made dorks — exposed documents, login portals, directory listings, config/backup files, and more. |
| `Shodan.html` | Shodan queries for internet-exposed services and devices — webcams, databases, industrial systems, default-credential banners, and more. |

Click any query to copy it, then run it in Google or Shodan.

## ⚠️ Use responsibly

These queries are for **authorized security testing, research and education only**. Only probe systems you own or have explicit written permission to test. Misuse may be illegal.
