# 🔎 Dorks

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![GitHub Pages](https://img.shields.io/badge/demo-live-brightgreen)](https://divshettyy.github.io/Dorks/Google.html)
[![PRs welcome](https://img.shields.io/badge/PRs-welcome-blue.svg)](CONTRIBUTING.md)

Curated **Google** and **Shodan** dork cheat-sheets for reconnaissance and OSINT — handy, ready-made search queries for finding exposed files, panels, devices and misconfigurations. Served as simple web pages via GitHub Pages, with a domain/keyword input so you can drop in your own target and go straight to the search results.

## 🌐 Open them

- **Google Dorking** → https://divshettyy.github.io/Dorks/Google.html
- **Shodan Dorking** → https://divshettyy.github.io/Dorks/Shodan.html

## 📋 What's inside

| Page | What it lists |
|------|---------------|
| `Google.html` | Google search operators and ready-made dorks — exposed documents, login portals, directory listings, config/backup files, and more. Dork list is pulled live from [TakSec/google-dorks-bug-bounty](https://github.com/TakSec/google-dorks-bug-bounty), so it stays current with that community list. |
| `Shodan.html` | Shodan queries for internet-exposed services and devices — webcams, databases, industrial systems, default-credential banners, and more. |

Enter a domain or keyword in the search box, then click any query to open it directly in Google or Shodan with that target applied.

## 🤝 Contributing

Found a dead dork, a better query, or want to add a new category? Contributions are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md) for how to submit one.

## ⚠️ Use responsibly

These queries are for **authorized security testing, research and education only**. Only probe systems you own or have explicit written permission to test. Misuse may be illegal.
